# EvoScientist

Use [kaist_evo_proxy](https://github.com/awesomesungminyu/kaist_evo_proxy) for
installation, workspace skills, and diagnostic feedback.

The older shell adapter takes a candidate and output directory. Set
`EVO_WORK_ROOT`, `EVO_DATA_ROOT`, and `EVO_TFL_ROOT` to prepared locations
as needed. The legacy agent launcher accepts an explicitly configured
HTTPS OpenAI-compatible endpoint. Set `CUSTOM_OPENAI_BASE_URL` for its
gateway and keep credentials in the launcher's local env file.
