# 도메인 우선 규칙 사전등록 (v4 최종 풀) — 2026-11-02

## 먼저 밝힐 점
- **이 규칙은 결과를 본 뒤에 만들었다.** 라운드 1~7의 점수·판별비·판정(`docs/CANDIDATE_POOL.md`, `docs/FINAL_POOL.md`(v3), `/workspace/s5_seed_check_20261031.md`, 라운드 7 표)은 규칙을 정하기 전에 이미 알려져 있었다. 특히 T2-R2-02(Lipophilicity)가 3시드 패 방향이고 기준 (4)만 미달(판별비 3.47233)이라는 사실을 알고 있었다.
- 규칙의 출처는 연구실 피드백이다: "승·패가 이미지·텍스트에 몰린 건 이해되지만, 비슷한 score에 다른 도메인 과제가 있으면 우선해서 넣자."
- 따라서 v4는 "사전에 정한 규칙을 적용한 결과"가 아니라 "피드백을 반영한 사후 규칙을 한 번 적용한 결과"다. 새 점수는 만들지 않았고(새 실험 없음), 기존 원점수와 판정을 재사용한다. 기존 합격 기준(1)~(5)과 문턱은 바꾸지 않는다.

## 규칙 (결과 표를 만들기 전에 확정)
같은 티어·방향 칸에 "예비·다양성 초과"로 표시된 과제(v3 기준 Tier 2 승 T2-R3-02 순열 EMNIST, Tier 2 패 T2-R2-01 SNLI)는 아래 조건을 **모두** 만족하는 후보로 교체한다.
1. 승패 방향이 3시드로 확인됐다(`s5_seed_check`의 3시드 판정 승/패, 엄격 부등호).
2. 기준 (1)~(5) 중 미달이 (4) 하나뿐이다(판별비 미달 외 사유 없음).
3. 판별비 ≥ 3.
4. 도메인이 그 칸의 확정 선택 과제들의 도메인과 다르다. 도메인은 `docs/TASK_ID_MAP.csv`의 domain 열을 쓴다.
5. 후보가 둘 이상이면 판별비가 큰 쪽을 고른다. 조건을 만족하는 후보가 없으면 예비를 유지한다.

그 밖의 것은 v3 그대로다: 확정 선택 과제, Tier 1 8칸, 칸 수(Tier 2 승 4·패 4)는 바꾸지 않는다. 교체된 과제는 v4 표에 "예비 → 교체됨"으로 남긴다.

## 적용 방법 (결과 확인 전에 고정)
- 후보 집합: 라운드 0~7의 Tier 2 과제 중 승 또는 패 방향이 한 번이라도 나온 것.
- 정규화 T−L은 `(기준선 보정 점수 T) − (L)`이며 정규화는 기존과 같다(기준선 0, 최적값 1; 낮을수록 좋은 지표는 최적값 0). 3라운드 이후 후보는 `decisions.json`의 `transformer_lstm_difference`, 0~2라운드는 원점수와 `docs/smoke_v21*_baselines.json`으로 계산한다.
- 3시드가 있는 과제(`s5_seed_check`)만 조건 1을 만족할 수 있다. 3시드 확인이 없는 후보는 이번 규칙으로 올리지 않는다(새 실험을 시작하지 않는다).

## 예상 (결과 확인 전에 알고 있던 것)
- Tier 2 패: SNLI → Lipophilicity 교체 예상.
- Tier 2 승: EMNIST를 대체할 비이미지 후보가 없으면 유지 예상.
